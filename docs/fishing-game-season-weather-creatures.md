# 钓鱼游戏季节天气鱼池设计

本文档参考《星露谷物语》的季节与天气思路：一年分为春、夏、秋、冬，天气会改变鱼类出现条件、咬钩速度、稀有度和收益。以下内容为本项目原创鱼池设计，可用于后续配置到 `game-data.ts` 或 `src/runtime/game.js`。

## 1. 基础规则

| 维度 | 设计 |
|---|---|
| 季节 | 春潮季、炎夏季、丰秋季、寒冬季 |
| 常规天气 | 晴、阴、雨、暴雨、雾、雷暴、雪 |
| 特殊天气 | 绿潮雨，仅夏季小概率出现，偏生态异变事件 |
| 鱼池逻辑 | 先按季节筛选，再按天气加权；特殊天气可追加隐藏鱼池 |
| 稀有度 | 普通、稀有、传说、隐藏、宝藏、垃圾 |
| 推荐鱼饵 | 蚯蚓偏浅水小型鱼，鲜虾偏海钓肉食鱼，亮片假饵偏高速大鱼，魔法鱼饵偏异种和传说 |

## 2. 天气效果

| 天气 | 玩法效果 | 推荐定位 |
|---|---|---|
| 晴 | 基准掉率，鱼群稳定，垃圾率正常 | 新手与日常收集 |
| 阴 | 咬钩等待 -8%，稀有鱼权重 +5% | 温和收益日 |
| 雨 | 咬钩等待 -18%，稀有鱼权重 +12%，浅水生物增多 | 快节奏钓鱼日 |
| 暴雨 | 咬钩等待 -25%，命中条速度 +15%，传说权重 +8% | 高风险高收益 |
| 雾 | 反应窗口 -12%，隐藏鱼权重 +8%，宝藏权重 +5% | 探索与神秘感 |
| 雷暴 | 命中条速度 +25%，隐藏鱼权重 +15%，宝藏权重 +12% | 高价值事件 |
| 雪 | 咬钩等待 +12%，冬季鱼权重 +25%，垃圾率 -5% | 冬季限定收集 |
| 绿潮雨 | 仅夏季，隐藏鱼权重 +20%，海草/藻类生物大量出现 | 限时异变事件 |

## 5. 掉率与权重建议

| 类型 | 基础权重 | 条件加权 |
|---|---:|---|
| 普通鱼 | 70% | 晴天 +5%，新手鱼饵 +10% |
| 稀有鱼 | 24% | 阴/雨/雾 +5% 到 +12% |
| 传说鱼 | 4.5% | 暴雨/雷暴 +5% 到 +8% |
| 隐藏鱼 | 0.5% | 雾/雷暴/绿潮雨 +8% 到 +20% |
| 宝藏 | 2% | 秋季 +3%，雷暴 +12%，雾 +5% |
| 垃圾 | 20% | 暴雨 +5%，雪天 -5%，高级鱼饵 -10% |

建议实现时不要直接把所有加成简单相加到 100% 以上，可先计算权重，再归一化抽取。这样后续增加宠物、装备、VIP 或活动加成时更稳。

## 6. 可落地数据字段

```ts
type SeasonTag = 'spring' | 'summer' | 'fall' | 'winter';
type WeatherTag = 'sunny' | 'cloudy' | 'rain' | 'storm' | 'fog' | 'thunder' | 'snow' | 'green_rain';

interface SeasonalFishItem {
  id: string;
  name: string;
  rarity: 'common' | 'rare' | 'legendary' | 'hidden';
  minW: number;
  maxW: number;
  price: number;
  icon: string;
  seasonTags: SeasonTag[];
  weatherTags: WeatherTag[];
  baitTags: Array<'worm' | 'shrimp' | 'lure' | 'magic' | 'divine'>;
  activeHours?: [number, number];
}
```
