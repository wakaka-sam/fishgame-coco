# 钓鱼游戏天气与季节系统方案

## 1. 方案目标

天气与季节系统的目标不是单纯换背景，而是给钓鱼主循环增加长期目标和每日变化。玩家每天进入游戏时能看到当前季节、今日天气和未来预报，并据此选择鱼饵、追目标鱼、规划收集。

第一期目标：

| 目标 | 说明 |
|---|---|
| 增加每日变化 | 每个游戏日固定一个天气，跨日后更新 |
| 增加季节收集 | 四季有不同鱼池和限定目标 |
| 增加预报系统 | 提供未来 3 天预报，帮助玩家准备鱼饵 |
| 影响钓鱼体验 | 天气影响咬钩等待、稀有度、命中条和奖励 |
| 保持实现可控 | 优先接入现有 `src/runtime/game.js` 主循环 |

## 2. 核心设计

### 2.1 日历规则

| 项目 | 建议值 | 说明 |
|---|---:|---|
| 一年季节数 | 4 | 春、夏、秋、冬 |
| 每季天数 | 7 天 | 小游戏节奏更快，28 天太长 |
| 一年总天数 | 28 天 | 方便循环 |
| 游戏日推进 | 每 6 小时真实时间推进 1 天 | 兼顾留存和变化频率 |
| 预报长度 | 3 天 | 不压 UI，又能形成准备感 |

季节计算：

```ts
const dayInYear = (gameDay - 1) % 28;
const seasonIndex = Math.floor(dayInYear / 7);
```

### 2.2 季节定义

| 季节 | 定位 | 鱼池特征 | 经济倾向 |
|---|---|---|---|
| 春潮季 | 新手友好、鱼群活跃 | 小型鱼、浅水鱼、雨天鱼多 | 稳定金币 |
| 炎夏季 | 高活跃、高风险 | 大型鱼、暴雨/雷暴鱼、绿潮雨异种 | 稀有与隐藏 |
| 丰秋季 | 收益季、宝藏季 | 高重量鱼、沉船系生物 | 金币与宝藏 |
| 寒冬季 | 限定收集季 | 冰雪鱼、深水鱼、雪天限定 | 图鉴与高价值鱼 |

## 3. 天气系统

### 3.1 天气类型

| 天气 | 可出现季节 | 玩法效果 | 场景表现 |
|---|---|---|---|
| 晴 | 全季 | 基准体验，普通鱼略多 | 明亮天空、水面高光 |
| 阴 | 全季 | 等待略短，稀有鱼小幅提升 | 低饱和天空 |
| 雨 | 春/夏/秋 | 咬钩更快，雨天鱼出现 | 雨线、水面涟漪 |
| 暴雨 | 夏/秋 | 咬钩快，命中条更难 | 大雨、浪高 |
| 雾 | 秋/冬 | 隐藏鱼和宝藏提高，反应窗口变短 | 低透明雾层 |
| 雷暴 | 春/夏/秋/冬低概率 | 隐藏鱼、宝藏提升，命中条更快 | 闪电、暗色天空 |
| 雪 | 冬 | 冬季限定鱼出现，咬钩较慢 | 雪粒、冷色水面 |
| 绿潮雨 | 夏季特殊 | 异种鱼池、隐藏鱼大幅提升 | 绿色雨幕、荧光水面 |

## 5. 鱼池规则

鱼池不要为每种天气完全复制一份，建议给鱼增加标签，用筛选和加权解决。

```ts
interface FishItem {
  id: string;
  name: string;
  rarity: Rarity;
  minW: number;
  maxW: number;
  price: number;
  icon: string;
  seasonTags?: Array<'spring' | 'summer' | 'fall' | 'winter'>;
  weatherTags?: Array<'sunny' | 'cloudy' | 'rain' | 'storm' | 'fog' | 'thunder' | 'snow' | 'green_rain'>;
  baitTags?: Array<'worm' | 'shrimp' | 'lure' | 'magic' | 'divine'>;
}
```

抽取流程：

1. 先按当前鱼饵拿基础鱼池。
2. 过滤 `seasonTags`，无标签的鱼默认全季可出。
3. 过滤或加权 `weatherTags`，天气命中时权重提高。
4. 按环境效果调整普通、稀有、传说、隐藏权重。
5. 先判断垃圾/宝藏，再从鱼池按权重抽鱼。

## 6. 天气预报

预报系统只需要保存未来 3 天，避免每次打开游戏都重新随机。

```ts
interface CalendarState {
  gameDay: number;
  lastTickAt: number;
  season: 'spring' | 'summer' | 'fall' | 'winter';
  todayWeather: WeatherId;
  forecast: Array<{
    gameDay: number;
    season: SeasonId;
    weather: WeatherId;
  }>;
}
```

生成规则：

1. 新用户创建 `calendar`，生成今日和未来 3 天天气。
2. 每次启动或回到前台时检查 `lastTickAt`。
3. 如果跨过游戏日，推进 `gameDay`，从旧 `forecast[0]` 取今日天气。
4. 预报不足 3 天时按季节概率继续补齐。
5. 保存 `calendar`，保证刷新不改变天气。

## 7. UI 与表现

| 入口 | 内容 |
|---|---|
| 顶部状态栏 | 当前季节、今日天气、剩余到下一天时间 |
| 天气按钮 | 打开 3 日预报弹窗 |
| 预报弹窗 | 日期、季节、天气、推荐鱼饵、可能出现的限定鱼 |
| 图鉴 | 标记季节限定、天气限定、未解锁条件 |
| 结算弹窗 | 显示“雨天稀有加成”“秋季宝藏加成”等来源 |
| 场景 | 根据季节换色，根据天气加雨雪雾雷等轻量效果 |

第一期 UI 建议只加一个顶部小入口：`春潮季 · 雨`，点击后打开预报。不要把天气信息做得太重，否则会挤压主玩法按钮。

| 第 6 阶段 | 平衡测试 | 抽样 1000 次确认收益和稀有率不爆炸 |

## 10. 第一版推荐范围

第一版建议只做这些：

| 必做 | 暂缓 |
|---|---|
| 四季循环 | 真实地理天气 |
| 8 种天气 | 月相、潮汐 |
| 3 日预报 | 复杂天气连锁事件 |
| 季节/天气鱼池标签 | 每条鱼独立复杂时段 |
| 简单场景特效 | 重粒子和高成本动画 |
| 天气影响数值 | 过多装备联动 |

这样第一期能明显提升内容深度，同时不会把小游戏主循环改得过重。
